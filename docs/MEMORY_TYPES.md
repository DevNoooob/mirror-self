# 记忆类型规范 types1

此规范用于提取与独立语义验证，唯一提示文本源是 [MemoryTypeGuidance](../src/main/java/com/mirrorself/memory/MemoryTypeGuidance.java)。未改变 Gold 或评分定义；没有重新调用模型证明真实改善。

| 类型 | 焦点和边界 | 时间、来源和审核 |
|---|---|---|
| FACT | 居住、角色、个人处境、当前使用的工具等个人事实。不能由“使用”推断熟练度。 | 断言时间独立判断，SOURCE_TIME 不等于今天仍然如此。 |
| EVENT | 有边界的一次经历、参与或已完成行动，焦点在某次事件。 | 明确过去则 HISTORICAL；不能将助手建议转为已执行。 |
| KNOWLEDGE | 用户明确学习过/正在学习/理解的主题、技能或知识主张。学习经历即使也是传记事实，仍优先此类；不由学习推断精通。 | 过去学习可以是 KNOWLEDGE/HISTORICAL，知识类型不等于当前掌握。 |
| OPINION | 明确的偏好、评价或观点。 | 保留否定和过去观点限定；不是人格结论。 |
| GOAL | 个人想要的未来结果、意向；包括保留完整条件及不确定性的低承诺考虑。 | 不能变成决定或已制定计划；纯假设、问题、他人意向不构成个人目标。 |
| THOUGHT_PROCESS | 人格、价值观、自我描述或思考/决策模式。 | 明确自述仍为 USER_EXPLICIT；推断只允许 MODEL_INFERRED。两者均进入 PENDING_REVIEW。 |

重叠时按语义焦点：思维/自我特质 → 未来意向 → 偏好评价 → 明确学习知识 → 有边界事件 → 其余受支持个人处境。顺序是消歧规则，不是机械关键词规则。参加一次课程活动侧重出席可为 EVENT；明确学习某个主题侧重学习为 KNOWLEDGE。不能复制同一命题赋予多个类型。

类型、来源、敏感度、时间是独立维度；仅在具有完整可验证句界时拆开独立表达，仍需逐字证据，不能改写 USER_EXPLICIT。证据不足时返回空，不用 FACT 兜底。

提示中提供六个通用英文 Few-shot（虚构学习主题、当前笔记工具、展会参与、安静工作偏好、条件性制作风筝意向、谨慎自述），不是九例答案。六个中文 held-out 合约测试使用另外的青禾语言、晨页、社团展览、草图偏好、木星模型与决策自述；均未参与九例 Live。

这些测试验证共享规范确实进入提取/语义提示、结构化类型/时间能进入原证据验证及审核策略，模型输出由 Mock 提供。**它们不证明 DeepSeek 已经学会分类，不得作为新的模型成绩。** 本次不实现针对 MQ032 或 Python/Java 词语的硬编码分类器。

MQ032 的已观测原因：旧提示只列出六个类型，详细说明了偏好/人格，却没有学习知识与一般事实的边界；G1 文本和 HISTORICAL 都正确，类型被归为 FACT，语义验证也没有阻止。这支持规范消歧方向，无法凭缺失的推理正文证明模型内部因果。新 LLM 提取器版本为 `llm-0.2.1-prompt2-types1-validator3`，真实效果仍需之后单独授权评估。
